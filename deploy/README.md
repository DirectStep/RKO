# РКО на REG.RU

Сервер: `89.111.173.217`, каталог `/opt/rko`. Кабинет: `https://app.xn--j1aalbgc.xn--p1ai`.

Используется production overlay. Всегда указывайте оба файла явно, чтобы локальный
`compose.override.yaml` с Cloudflare Tunnel не подключался:

```sh
docker compose -f compose.yaml -f compose.production.yaml up -d --build db bot caddy
```

Перед первым запуском задайте в серверном `.env` случайный `POSTGRES_PASSWORD`
и тот же пароль в `DATABASE_URL`. `.env` хранится с правами 600; токены и
Google credentials передаются отдельно от Git. Родительский каталог `/opt/rko`
доступен только root. Каталог `secrets` и Google JSON должны быть читаемы
непривилегированным пользователем контейнера.

DNS для `app.ркорко.рф`: запись A на `89.111.173.217`, режим DNS only.
Она заменяет прежний Tunnel `rko-local` только после восстановления базы и
переключения ботов. Корневой домен и www не изменяются. Caddy автоматически
получает и обновляет HTTPS-сертификат; входящие TCP 80 и 443 должны быть открыты.
База не публикует порт; порт приложения доступен только на localhost.

Перед переключением остановите локального бота и туннель. Снимите финальную
копию базы, восстановите её на сервере и сверьте количество строк всех таблиц.
Одновременно запускать локальный и серверный polling с одинаковыми токенами нельзя.

`rko-backup.timer` сохраняет копии в `/var/backups/rko` ежедневно около 03:00
по Москве и хранит их семь дней. Установите unit-файлы в `/etc/systemd/system`,
затем выполните `systemctl daemon-reload` и
`systemctl enable --now rko-backup.timer`. Копии на том же сервере не защищают
от его потери: скачивайте копии отдельно, сохраняйте `.env` и Google credentials.

Проверки: `docker compose -f compose.yaml -f compose.production.yaml ps`,
`docker compose -f compose.yaml -f compose.production.yaml exec -T bot python3 -m app.healthcheck`,
HTTPS `/` возвращает 200, `/api/session` без Telegram-подписи возвращает 401.

При откате сначала остановите серверный бот. Не восстанавливайте старый локальный
снимок поверх новых серверных данных: сначала сохраните свежую копию сервера и
перенесите её обратно. Для возврата на ноутбук сначала получите токен `rko-local`
в Cloudflare и проверьте соединение: прежний локальный файл токена отсутствует.
Только после этого возвращайте DNS на Tunnel и запускайте локального бота.
Не используйте `docker compose down -v`.
